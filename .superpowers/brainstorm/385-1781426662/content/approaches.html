神兽收集 — How does the user collect beasts?

The core loop: discovery → encounter → collect. Each approach creates a different emotional experience.

A

Exploration Map 🌏

A map of mythical China divided into regions (Kunlun Mountains, Eastern Sea, Southern Jungles, Western Deserts, Northern Wastes, Heavenly Realm, Underworld). Each region has 3-5 native beasts. Users click a region to "explore" — a short narrative encounter plays out, and a beast is revealed. Some beasts are rare (low encounter rate). Feels like a journey through Chinese mythology.

Collection size: ~25-30 beasts across 7 regions

B

Daily Discovery 🔮

Each day, a new beast "appears" — presented as a beautiful illustrated card with lore, stats, and mythology. One free discovery per day. Missed beasts go into a "missed encounters" pool that can be revisited (with patience). Simple, contemplative, low-pressure. Like receiving a daily gift from the mythic world.

Collection size: ~30 beasts, 30-day completion

C

Scroll Unlock System 📜

All beasts are visible from the start as "shadowed" entries in a bestiary grid. Users unlock them by completing themed challenges (e.g., "Read 3 dragon articles" unlocks dragons, "Visit 5 deity pages" unlocks guardian beasts). Cross-links to the rest of the site. Educational — drives engagement with the knowledge base.

Collection size: ~20 beasts, each with an unlock condition

D

Hybrid: Explore + Daily + Bestiary

Map-based exploration (A) with daily bonus encounters (B) and a full bestiary grid (C). Most feature-rich but most complex to build. Exploration drives discovery, daily visits rewarded, bestiary tracks completion.

Collection size: ~30 beasts across 7 regions
