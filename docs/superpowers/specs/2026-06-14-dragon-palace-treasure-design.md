# 龙宫探宝 (Dragon Palace Treasure) — 游戏设计

**日期**: 2026-06-14
**状态**: Approved

## 概述

顶视角水下探索收集战斗游戏。玩家扮演**白龙马**（东海龙王三太子）在深海各层游动寻宝，击败海怪，管理氧气，不断向更深层下潜。

---

## 文件结构

```
games/dragon-palace-treasure/
├── index.html          ← 游戏页面（SEO + Canvas + HUD DOM）
├── css/game.css        ← 水下主题样式
└── js/
    ├── game.js         ← 完整游戏引擎
    └── audio.js        ← 复用或改编 Havoc in Heaven 的音频引擎
```

---

## 一、核心玩法

顶视角水下探索 + 收集 + 自动攻击。每层需收集足够珍宝开启下潜通道到下层的深海区域，同时应对越来越强的海怪。

## 二、深度层级

| 层 | 名称 | 视觉基调 | 敌人 | 珍宝 | 通关条件 |
|---|------|----------|------|------|----------|
| 1 | 浅海珊瑚 | 明亮蓝绿、阳光透射 | 小鱼群（无害） | 珍珠、珊瑚 | 收集 10 珍宝 |
| 2 | 龙宫外院 | 深蓝、宫殿柱影 | 巡海夜叉、水母 | 银元宝、水晶 | 收集 12 珍宝 |
| 3 | 深海裂谷 | 暗蓝、生物荧光 | 海蛇、电鳗、鲨鱼 | 金元宝、夜明珠 | 收集 15 珍宝 |
| 4 | 龙宫宝库 | 金碧辉煌 | Boss（龙宫将军/龟丞相） | 龙珠、定海神珍 | 击败 Boss |
| 5+ | 无尽深渊 | 墨黑、发光粒子 | 混合 + Boss 循环 | 传说级珍宝 | 收集 18+ |

## 三、三项资源

- **HP** — 被敌人攻击扣血，归零死亡
- **氧气** — 持续消耗，越深消耗越快。找到气泡柱补充 30%。耗尽后 HP 快速持续下降
- **深度分** — 越深得分倍率越高（1x→1.5x→2x→3x...）

## 四、敌人系统

| 敌人 | 出现层 | 行为 | 掉落率 |
|------|--------|------|--------|
| 小鱼群 | 1 | 无害穿梭，装饰性 | — |
| 水母 | 2+ | 缓慢漂移，碰触麻痹减速 2s | 15% |
| 巡海夜叉 | 2+ | 巡逻追踪玩家，近战攻击 | 20% |
| 海蛇 | 3+ | 快速直线冲刺 | 20% |
| 电鳗 | 3+ | 远程放电弹 | 18% |
| 鲨鱼 | 4+ | 高速追击，高伤害 | 25% |
| 龙宫将军(Boss) | 每 4 层 | 高血量 + 召唤小兵 | 必掉 3 个道具 |
| 龟丞相(Boss) | 每 4 层交替 | 慢速但高血量、范围攻击 | 必掉 3 个道具 |
| 龙王(Boss) | 每 8 层 | 最终 Boss，全屏攻击 | 必掉 5 个道具 |

所有敌人用 Canvas 绘制风格化海洋造型（鱼形、蛇形、龙形剪影+荧光）。

## 五、道具系统

从击败敌人掉落（非 Boss 15-25%，Boss 必掉）：

| 道具 | 稀有度 | 效果 |
|------|--------|------|
| 气泡 | 常见 | 恢复 30% 氧气 |
| 龙息冲击 | 常见 | 前方锥形范围伤害（2x） |
| 水盾 | 罕见 | 吸收 3 次伤害，持续 8s |
| 疾游 | 罕见 | 游速翻倍，持续 5s |
| 龙威 | 稀有 | 全屏震晕敌人 3s |
| 海灵珠 | 稀有 | 磁铁吸引附近所有珍宝 5s |
| 龙珠 | 传说 | 满血+满氧+10s 无敌 |

## 六、操作

- WASD / 箭头键 / 手机摇杆：八方向游动
- 自动攻击（锁定最近敌人，间隔 0.6s）
- 空格：暂停
- 移动端：虚拟摇杆（复用 Havoc in Heaven 模式）

## 七、视觉风格

- Canvas 2D 绘制水下世界
- 背景：按深度层级渐变（浅→深蓝→黑），带气泡粒子、海藻、珊瑚
- 玩家：白龙马龙形剪影（用 `images/white-dragon-horse/wlh-hero.jpg` 做头像）
- 珍宝：发光圆点，越高级越大越亮
- 气泡柱：随机位置出现，向上冒泡的视觉
- 深度通道：屏幕边缘出现漩涡/光柱标记下潜方向

## 八、音效（Web Audio API 合成）

- 水下环境音（低频嗡鸣 + 气泡声）
- 攻击：水波冲击声
- 受伤：低沉撞击
- 收集珍宝：清脆叮咚
- 下潜：深海漩涡声
- Boss 警报：急促鼓点
- 死亡：深沉水压坍塌声

## 九、HUD

- 左上：HP 条 + 氧气条 + 深度层数
- 右上：珍宝收集数 / 目标数 + 分数
- 底部：活跃技能/道具图标 + 倒计时
- 游戏结束：显示深度、分数、珍宝数 + "再探龙宫" 按钮

## 十、与 Havoc in Heaven 的关系

- 复用音频引擎架构（`audio.js`）
- 复用摇杆控制逻辑
- 独立的游戏引擎（`game.js`）
- 独立的视觉主题（`game.css`）
- 共享 `js/deities.js` 中的 `CELESTIAL_GAMES` 注册
