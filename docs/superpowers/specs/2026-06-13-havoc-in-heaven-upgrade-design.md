# 大闹天宫 — 全面升级设计

**日期**: 2026-06-13
**状态**: Approved

## 概述

对 `games/havoc-in-heaven/` 的顶视角生存 Roguelike 游戏进行全面视觉和音频升级。

## 架构

```
games/havoc-in-heaven/
├── index.html          ← 修改：死亡/庆祝 DOM
├── css/game.css        ← 修改：新 overlay 样式
└── js/
    ├── game.js         ← 修改：玩家头像渲染、敌人重绘、跳跃、庆祝/死亡逻辑
    └── audio.js        ← 新增：Web Audio API 音效引擎
```

## 一、孙悟空头像替换圆球

**当前**: 玩家是金色圆形 (`ctx.arc()` 绘制)
**目标**: 用孙悟空头像图片替换

- 预加载 `images/sun-wukong/sun-wukong-hero.jpg` 为 Image 对象
- 用 `ctx.drawImage()` + `ctx.clip()` 圆形裁剪绘制头像
- 保留金色光晕 `glowGrad` 叠加在头像下方
- 移动时头像微微朝向移动方向旋转（±15°）
- 攻击/技能闪烁效果保留叠加在头像上

## 二、天兵天将 + 五行元素敌人

全部用 Canvas 2D 绘制风格化造型。每种敌人类型有独特视觉+游戏机制：

| 元素 | 敌人类型 | Canvas 视觉 | 特殊机制 |
|------|---------|-------------|----------|
| 金 | 金甲兵/武将 | 金色方形+头盔纹、金属光泽 | 伤害减免 20% |
| 木 | 藤甲兵 | 绿色多边形+藤蔓缠绕、回血粒子 | 每秒回复 2% HP |
| 水 | 冰弓手 | 蓝色菱形+冰晶拖尾、远程冰箭 | 命中减速玩家 30%，2s |
| 火 | 火骑兵 | 红色三角+火焰尾迹、速度快 | 碰撞附加灼烧 DOT，3s |
| 土 | 巨灵神 | 黄色大圆+岩石纹理、Boss级 | 高血量、低速度 |

每种敌人绘制方式:
- 用 Canvas 路径画出基础形状（方/菱/三角/圆等），替代纯圆
- 叠加元素粒子特效（火花、冰晶、尘土等）
- Boss 保留血条 + 名字显示
- 远程敌人画出箭矢弹道

## 三、跳跃系统

- **触发**: 双击前进方向键（W/↑）或双击摇杆前推 → 向移动方向跳跃
- **位移**: 80px
- **空中时间**: 0.15 秒，纯位移无无敌帧
- **冷却**: 0.6 秒
- **视觉**: 跳跃弧线粒子轨迹
- **HUD**: 跳跃冷却指示图标

## 四、三级动态音频

全部用 Web Audio API 合成，无需外部音频文件。

### 背景音乐（三级紧张度）

| 级别 | 触发条件 | 音乐特征 | BPM |
|------|----------|----------|-----|
| 平时 | Wave 1-7, HP > 40% | 舒缓鼓点 + 五声音阶旋律 | 80 |
| 紧张 | HP ≤ 40% 或 Wave ≥ 8 | 加快鼓点 + 低音嗡鸣 | 120 |
| Boss | 每 5 波出现 Boss | 重鼓 + 急促旋律 + 金属撞击 | 160 |

过渡: 级别变化时音乐在 2 秒内平滑过渡。

### 音效列表

| 事件 | 合成方式 |
|------|----------|
| 攻击 | 短促噪声 + 共振滤波器模拟金属棒击 |
| 受伤 | 低音撞击 |
| 杀敌 | 元素对应的消散声（金=金属,木=木裂,水=冰碎,火=火焰,土=石碎） |
| 升级 | 金色钟声 + 上升琶音 |
| 死亡 | 沉重鼓击 + 低音衰减 |
| 跳跃 | 风声扫过 |
| 火眼金睛 | 火焰咆哮 |
| 定身术 | 冰冻凝结 |
| 大圣归来 | 巨大爆炸冲击波 |
